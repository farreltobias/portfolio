# SEO

## Strategy

The portfolio's SEO goal is narrow: rank for Farrel's name and appear correctly when shared on LinkedIn, Slack, and other professional channels. Broad keyword targeting is not a priority.

**Primary targets**:
- "Guilherme Farrel" (name search)
- "Guilherme Farrel engineer" / "Guilherme Farrel portfolio"
- Case study and insight pages: indexable for specific technical topics

---

## Meta Tags

Every page must have:

```html
<title>{page title} — Guilherme Farrel</title>
<meta name="description" content="{page-specific description, 120–160 chars}" />
<link rel="canonical" href="{absolute URL of this page}" />
```

**Title format**:
- Home: `Guilherme Farrel — Product Engineer`
- Work: `Work — Guilherme Farrel`
- Case Study: `{case study title} — Guilherme Farrel`
- About: `About — Guilherme Farrel`
- Insights: `Insights — Guilherme Farrel`
- Insight: `{insight title} — Guilherme Farrel`
- Contact: `Contact — Guilherme Farrel`

**Description sources**:
- Home: `site_description` from Settings
- Singletons (Work, About, Insights): `meta_description` field on the singleton document
- Case Study / Insight: `meta_description` field on the document; fallback to `excerpt` / `outcome_summary`

---

## Open Graph

Every page must include full OG tags for LinkedIn and Slack previews.

```html
<meta property="og:title" content="{page title}" />
<meta property="og:description" content="{page description}" />
<meta property="og:type" content="{website | article}" />
<meta property="og:url" content="{canonical URL}" />
<meta property="og:image" content="{OG image URL}" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:site_name" content="Guilherme Farrel" />
```

**OG image strategy**:
- Default: `og_image` from Settings singleton (1200×630px, stored in Prismic)
- Case Study / Insight: document-level `og_image` if set; fallback to Settings default
- Automated OG image generation (Vercel OG) is a Phase 6 backlog item — not in initial scope

**`og:type`**:
- Home, Work, About, Insights, Contact: `website`
- Case Study, Insight: `article`

---

## Twitter / X Cards

```html
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="{page title}" />
<meta name="twitter:description" content="{page description}" />
<meta name="twitter:image" content="{OG image URL}" />
```

No `twitter:site` or `twitter:creator` unless Farrel has an active Twitter/X account to link.

## Structured Data

### Person (Home page)

```json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Guilherme Farrel",
  "url": "https://portfolio.farrel.tech",
  "jobTitle": "Product Engineer",
  "sameAs": [
    "https://linkedin.com/in/{handle}",
    "https://github.com/{handle}"
  ]
}
```

### Article (Insight pages)

```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "{insight title}",
  "datePublished": "{published_date ISO 8601}",
  "author": {
    "@type": "Person",
    "name": "Guilherme Farrel"
  }
}
```

Structured data is injected as a `<script type="application/ld+json">` in the page `<head>` by the layout component. It is generated server-side from Prismic data — no client JS.

## Sitemap

Auto-generated by `@astrojs/sitemap`. Configure in `astro.config.mjs`:

```js
import sitemap from '@astrojs/sitemap'

export default defineConfig({
  site: 'https://portfolio.farrel.tech',
  integrations: [sitemap()],
})
```

All public pages are included. No exclusions needed at launch.

No disallow rules. The portfolio is fully public and indexable.

---

## Canonical URLs

- All pages use absolute canonical URLs
- Trailing slash policy: no trailing slash (enforce consistently)
- `www` vs. apex: pick one, redirect the other at the Vercel level
- Prismic preview URLs must not be indexed — they operate on `*.prismic.io` domains and are not in scope

---

## Performance and Core Web Vitals

SEO is partly a function of performance. See `ARCHITECTURE.md` for performance targets.

Key rules:
- All images use Astro's `<Image>` component with `width`, `height`, and `alt` — no layout shift
- Fonts are loaded with `font-display: swap` and preloaded for the critical weight
- No render-blocking scripts
- Prismic images served via Prismic CDN with format conversion (webp/avif via `imgix` params)
