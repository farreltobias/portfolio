# Work

Scope: the Work index (`src/pages/work/index.astro`). Inherits the Home world (`src/styles/home.css`); shares the index row with Home's Selected work.

Visitor mode: **Experience** (portfolio index): one decision per screen — which sheet to open.

Audience/job: evaluators who want more than Home's featured set; scan every project's constraint, decision and outcome, then open one. Content: every entry in the project collection, in `order`. No filters, tags or sorting controls.

Constraints: rows render every outcome state (figure only with metric + figure; ink sentence; dot mask); no per-project rasters; no client JS.

## Direction contract

THESIS: The register of the drawing set — every sheet listed once, in the same three fields, so projects read against each other. It refuses the card grid of thumbnails.

OWN-WORLD: Home's field, hairlines, condensed caps, tracked labels, mono values, hatch notation and magenta-only-for-measured-delta (widened by Farrel, 2026-10-16: magenta marks any recorded before → after figure, keyed "Before → after", plus focus); Home's index row, unchanged.

STORY: The visitor sees how much work there is, compares constraints and outcomes down one ruled column, and opens the sheet that matches their problem.
